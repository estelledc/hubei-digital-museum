# 文物覆盖盘点与后续数字化计划

盘点日期：2026-09-07。基线：公开版 v0.13.0，源码提交 `f286446`。状态：**本轮研究收尾；后续建模未启动**。

当前项目有 11 个展区、16 组文物与展陈模型；本次整理 **32 项尚未纳入项目的制作候选**，另列已有模型的精度欠缺。馆方十大镇馆之宝中，项目已有 8 个名称对应的模型，缺少郧县人头骨化石和彩绘人物车马出行图。这个 8/10 只表示名称覆盖，不表示八件都已完整、高精度数字化。

## 统计口径与证据

- “尚未纳入”指本项目公开资产、展品注册表和交互工程中未覆盖，不表示馆方或其他机构没有数字化。
- 32 项按制作任务计数，有单件、器物组合、成组简牍，不是 32 件实物。它们是有公开出处的优先候选，**不是全馆未建模藏品的穷尽清单**。未取得全馆逐件在展目录，不能计算全馆藏品覆盖率。
- 官方典藏页证明有公开著录；旧介绍中的展位不作为现馆定位依据。“拟放展区”是本项目后续安排建议，每件入厅前仍须核对展签、原件／复制品身份及当期展位。暂时不能确认的，先做独立文物卡。
- 本轮实际检查 `web/lib/museum.ts`、`web/lib/artifact-experiences.json`、发布清单，并读取全部 32 个 `.glb.gz` 的 GLB JSON。11 个展厅中的文物标识与 16 个注册项相符；演奏厅的 `bells-performance-copy` 是重复演示资产，不另计文物。
- 馆方[虚拟展览目录](https://www.hbww.org.cn/xnzl/index.html)已有曾侯乙、曾世家、楚国八百年、梁庄王、天籁、陶瓷及通史展等入口。本轮核对了目录，未逐件验证其中的可旋转模型，未获取可再分发扫描文件。因此，下表各项的“馆方单件三维资产是否存在／可取得”均为**未知**，不是“没有”。

### 本次资料范围

以馆方[常设展览](https://www.hbww.org.cn/cszl/index.html)、[镇馆之宝](https://www.hbww.org.cn/zgzb/index.html)为主；读取青铜器目录第 1—5 页，漆木器、金银器、玉器、陶瓷、竹木简牍目录各第 1 页，以及相关详情和展览介绍。书画、古籍及其余目录分页未全面盘点，作为后续资料任务保留。

检索通过 `journal-search public`，Exa 和 GitHub 后端均返回成功；搜索条目仅作候选。引用正文通过公开域名的直接 fetch 获取，bundle 完整性验证通过，再读取文本；这不构成影像许可或文物精度证明。原始网页和未授权图片不写入公开仓库，仅保留消化后的结论与链接。

启动时先安排一个不超过 2 个工作日的资料试查窗口，检查 P1 是否真的具备建模输入；拿不到输入就记录缺项和下一条可行来源，不连续生成猜测模型。具体制作工期在两件试制验收后估算；授权等待和高精度扫描获取不纳入未经确认的工期承诺。

### 资料收集顺序

1. 馆方典藏详情、当期展签／虚拟展览：确认“是哪件”和“放在哪里”，记录页面访问时间。
2. 考古报告、馆方研究、保护修复论文：补器号、尺寸、分件方式和原貌。比如 N11 的网页出现不合比例的宽度记录，不能直接照值建模。
3. 已有开放许可摄影或经许可自行拍摄：正、背、左、右、俯、底面及关键局部，尽量记录拍摄角度、尺标和光线；同名不同器号不得混用。实景视频用于位置与动作辅助判断，不能自动替代测绘。
4. 馆方可授权三维资源：核对扫描对象、处理方式、单位、纹理与许可。只有全景入口或网页展示，不算已取得可下载三维资产。需要向馆方咨询时先准备具体资源与使用范围清单，当前未发起联系。

### 每项交付与验收

- **身份和几何**：记录名称、出土单位／器号、原件或复制品、已知尺寸和未知面；Blender 单位一致。至少正、背、侧、俯视与所用参考对照；透雕、孔洞、薄边和器物残缺应在几何中可见，增加面数不能代替轮廓正确。
- **颜色与表面**：区分青铜锈层、金银、玉石、漆木、胎釉；减小展柜反光和混合光色偏。照片、纹理与衍生物逐项可公开；未知背面标明近似。简牍、铭文和底款必须对应来源中的实际文字。
- **交互**：可活动部位有依据才运动；分区爆炸图只是观察方式，界面明确它不等于真实拆卸。首批需验证点击选择、展开／演示、复位、切换文物和减少动态效果设置，不能出现悬浮零件、残留动作或穿模。
- **网页与 Blender**：沿用现有模型加载和交互结构，交付可编辑工程及对应 `.glb.gz`；增补对应的实际模型检查，并运行 `npm test`、`npm run typecheck` 和带仓库子路径的构建。另在浏览器实际走文物进入、加载、交互、返回路径，保存视觉对照和设备信息；自动模型测试不能替代这一环。
- **体积**：逐件记录压缩字节数与首次加载表现，按需加载；大型组合拆成可选细节，不让每次入馆下载全部藏品。细节取舍以已验收的视觉结果为界，不为了文件小再次退回玩具感。
- **接受与发布**：维护者明确接受后更新注册表、对应展厅、来源说明与 Release；“资料齐备”“模型生成”“浏览器验证”“视觉接受”“公开上线”分别记录，不合写成一个“完成”。
