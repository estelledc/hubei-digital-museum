# 来源与公开版边界

以现馆为依据；公开资料不足处允许近似重建并标明。这是个人研究展示，不是馆方数字孪生或扫描资产。

- [湖北省博物馆](https://www.hbww.org.cn/)：展览目录、代表文物名称及公开尺寸。展位会变化；资料记录主要整理于 2026 年 7—9 月。
- [中信建筑设计：湖北省博物馆三期](https://design.citic/portal/article/index/id/3220.html)：公共空间、树形柱、旋梯、立面与新旧馆关系。尺寸和不可见区域仍近似。
- [B站：湖北省博物馆游览教程](https://www.bilibili.com/video/BV1UcfCBmEqE/)：观察了约 00:15 的三层通道画面，用于材料和衔接判断，未据此推定完整平面。
- [编钟演奏参考一](https://www.bilibili.com/video/BV1H3NZzfEBa/)与[参考二](https://www.bilibili.com/video/BV1bJ4m1K7xE/)：击奏动作与器具示范的研究入口。没有分发视频、音轨或截图。
- [开放照片纹理署名](fidelity-credits.md)：剑、梅瓶和方鼎使用的 CC BY-SA 4.0 照片及衍生纹理。

公开版移除了尚未确认再分发许可的馆方与 VR 照片贴图。竹简文字、稿本页、金锭铭文、玉雕等部分精细表面因此不展示。替代材质仅表示近似色彩，不代表对原纹饰的恢复。

园区与公共空间四组渲染图来自本项目 Blender 几何和程序材质，随站点展示；建筑师和馆方实拍图不在公开目录内。
